Ambiguous Iframe Attributes Test

This page is for duplicate-attribute fallback testing. Both iframes share the same name and class so the resolver should reject those candidates as ambiguous, then move on to the next unique attribute.

Expected behavior: name and class should be ambiguous, while the iframe title should still uniquely identify the intended frame.

Primary iframe

Has the same name and class as the sibling frame, but a unique title and id.

Sibling iframe

Shares the duplicate attributes but should not be selected when the resolver falls through to the unique title.
