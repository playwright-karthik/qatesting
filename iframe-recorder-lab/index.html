Iframe Recorder Lab

Shared fixtures for testing recorder behavior inside iframe contexts. The child iframe pages reuse the same control set so we can compare single-frame, double-frame, and chained frame-path resolution paths without depending on third-party pages.

Use these pages to validate element selection, frame-path chaining, and iframe-scoped interactions such as text input, checkbox, radio, dropdown, button, and link navigation. The nested iframe page is the one to use when you want to confirm multi-hop frame resolution.
